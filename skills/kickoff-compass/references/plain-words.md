# Plain words (for beginners)

Use the short version the first time a term appears. Don't paste this whole list at the person.

| Term | Say it like this |
|---|---|
| Frontend | The part people see and click |
| Backend | The engine behind the screen that does the work |
| API | A menu of requests one program can make to another |
| Database | Where the app remembers things |
| Server / host | A computer that keeps the app running for others |
| Deploy | Put the app online so others can use it |
| Repository (repo) / GitHub | A folder that remembers every change, saved online |
| Commit / push | Save a checkpoint / upload checkpoints to GitHub |
| Environment (venv, node_modules) | A private toolbox for this one project |
| Dependency / package | A ready-made building block someone else wrote |
| `.env` file | A private note on your computer holding passwords and keys; never shared |
| API key | A password that lets your app use a paid service |
| Model / LLM | The AI brain that reads and writes text |
| Prompt | The instructions you give the AI |
| Token | A small chunk of text; AI services charge per token |
| RAG | Letting the AI look things up in your documents before answering |
| Agent | An AI that can take actions using tools, not just chat |
| Tool (for AI) | An action the AI is allowed to do, like "search orders" |
| Prompt injection | Tricking the AI with hidden instructions in text it reads |
| MVP | The smallest version that proves the idea works |
| Test | A small automatic check that something still works |
| CI | A robot that runs the tests every time code changes |
| Authentication / login | Proving who you are |
| Authorization / permissions | What you're allowed to do once logged in |
| Logs | The app's diary of what happened |
| Latency | How long you wait for an answer |
| Docker | A sealed box that runs the app the same way everywhere |
| Open source | Free code anyone can read and use |
| Rate limit | A cap on how many requests are allowed per minute |
| Multi-tenant | One app serving many separate companies, each seeing only their own data |
| Hand-over (escalation) | When the AI passes a conversation to a real person |
| Go live | Switch it on for real customers |
| Test mode / sandbox | A practice version where nothing real happens |
| Integration / connection | Linking two apps so they can share information |
| ATS (applicant tracking system) | Software that collects and sorts job applications |
| Baseline | How things are today, so we can measure the improvement |
| Pilot | A small, careful trial with a few real users |
